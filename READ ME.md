# Agente Estratégico de Marketing y Búsqueda Laboral

Agente de Inteligencia Artificial desarrollado con la API REST de Google Gemini, personalizado para asistir a Nicolas en análisis de marketing estratégico, ventas y preparación para su perfil profesional.

## 🚀 Características
- **Privacidad de API Key:** Se solicita en pantalla y se guarda localmente en el navegador (`localStorage`), sin exponer la clave en el código de GitHub.
- **Formato dinámico:** Procesa texto en formato Markdown para facilitar la lectura.
- **Exportable:** Genera informes descargables en HTML con un solo clic.

## 🛠️ Instalación y Uso en GitHub Pages
1. Obtén tu API Key gratuita en [Google AI Studio](https://aistudio.google.com/).
2. Entra a la URL publicada por GitHub Pages.
3. Al enviar tu primer mensaje o presionar el botón **🔑 Configurar API Key**, pega tu clave.
